\# 🔍 Fundamentos de Investigación - Ciclo V



\## 🎯 Objetivo

Desarrollar habilidades críticas para la lectura y redacción de artículos científicos.



\## 📝 Temas Clave (Preparación)

1\. \*\*Búsqueda Bibliográfica:\*\* Uso de PubMed, Pedro y Google Scholar.

2\. \*\*Niveles de Evidencia:\*\* Desde opiniones de expertos hasta Metaanálisis.

3\. \*\*Variables:\*\* Dependientes, independientes e intervinientes.

4\. \*\*PICO:\*\* Estructura de la pregunta de investigación.



\## 🛠️ Integración Proyecto CJ

\- Buscador RAG para conectar PDFs con evidencia científica.
