\# 👴 Rehabilitación en Geriatría - Ciclo VI



\## 🎯 Objetivo

Mantener la funcionalidad y calidad de vida del adulto mayor mediante el movimiento.



\## 📝 Temas Clave (Preparación)

1\. \*\*Síndromes Geriátricos:\*\* Sarcopenia, fragilidad y riesgo de caídas.

2\. \*\*Evaluación Funcional:\*\* Escalas de Tinetti, Barthel y Katz (esenciales para el seguimiento).

3\. \*\*Fisiología del Envejecimiento:\*\* Cambios en el sistema osteomuscular y sensorial.

4\. \*\*Ejercicio Multicomponente:\*\* Entrenamiento de fuerza, equilibrio y marcha.



\## 🛠️ Integración Proyecto CJ

\- Base de datos de ejercicios adaptados para la prevención de caídas.
