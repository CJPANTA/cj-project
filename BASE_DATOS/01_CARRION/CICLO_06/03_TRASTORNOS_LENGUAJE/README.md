\# 🗣️ Trastornos del Lenguaje - Ciclo VI



\## 🎯 Objetivo

Identificar alteraciones en la comunicación para el abordaje multidisciplinario.



\## 📝 Temas Clave (Preparación)

1\. \*\*Afasias:\*\* Tipos (Broca, Wernicke) y su relación con el ACV.

2\. \*\*Disartria y Disfagia:\*\* Manejo de la musculatura orofacial y deglución.

3\. \*\*Comunicación Aumentativa:\*\* Sistemas de apoyo para pacientes no verbales.

4\. \*\*Desarrollo del Lenguaje:\*\* Hitos normales vs. signos de alarma.



\## 🛠️ Integración Proyecto CJ

\- Glosario de términos para facilitar la lectura de informes médicos.
